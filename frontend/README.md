# TestForge Frontend

Modern QA Automation & Test Management Dashboard for TestForge.

## Features

- **QA Metrics Dashboard**: Real-time pass rates, latency benchmarks, and active defect tallies.
- **AI Test Generator Form**: Turn user stories into structured API test suites with one click.
- **Interactive Test Runner**: Run individual tests or full regression batches with assertion feedback.
- **Root-Cause Defect Modals**: AI-assisted bug diagnosis with reproducible steps and copyable Jira tickets.

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run local dev server**:
   ```bash
   npm run dev
   ```

3. **Production build**:
   ```bash
   npm run build
   ```
